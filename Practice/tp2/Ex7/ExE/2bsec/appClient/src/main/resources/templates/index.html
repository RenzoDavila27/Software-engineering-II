Sobre El Sistema

Biblioteca Fioritech es una plataforma integral para la administracion de colecciones, socios y autores en bibliotecas modernas.

Nuestro panel permite registrar nuevos ejemplares, actualizar existencias y conocer el historial completo de prestamos. Incluye alertas automaticas para devoluciones y reportes que muestran los titulos mas consultados, ayudando a priorizar compras futuras.
